# НПП «Стек» — новый сайт

Статический сайт (HTML + CSS + JavaScript) на основе контента и каталога bostek.ru.
42 модели, 18 категорий, заявка-корзина, модальные карточки товаров, формы обратной связи.

## Как открыть

Просто откройте `index.html` в браузере — сайт работает по `file://`, сервер не нужен.
Все данные каталога лежат в `data.js` и подключаются обычным `<script>`.

Для проверки по HTTP можно запустить любой статический сервер в этой папке, например:

```
npx serve .
```

## Структура

| Файл / папка | Назначение |
| --- | --- |
| `index.html` | Главная страница: hero, каталог, преимущества, процесс, FAQ, контакты, модалка, корзина заявок |
| `privacy.html` | Политика обработки персональных данных |
| `styles.css` | Все стили: тёмная тема, градиенты, анимации, адаптив |
| `app.js` | Каталог, фильтры, поиск, сортировка, корзина, формы, модальные окна |
| `data.js` | Сгенерированные данные: 42 товара, 18 категорий, характеристики |
| `assets/products/` | Фотографии товаров (по ID), `placeholder.svg` — заглушка |
| `assets/sertif-640.jpg` | Сертификат официального поставщика Сбербанка |
| `data/products.json` | Исходные данные, полученные со старого сайта |
| `raw/` | Архив HTML старого сайта (для повторного парсинга) |
| `build-data.mjs` | Генератор `data.js` из `data/products.json` |
| `reparse.mjs` | Повторный разбор карточек из `raw/` |
| `scraper.mjs`, `scrape-extra.mjs` | Скрипты сбора данных со старого сайта |

## Обновление каталога

1. При необходимости поправьте `data/products.json`.
2. Выполните:

```
node build-data.mjs
```

Скрипт пересоберёт `data.js` и выведет список товаров. Точечные правки подписей
(размеры, характеристики) задаются в `CHIP_FIX`, `DESC_FIX`, `TITLE_FIX` внутри `build-data.mjs`.

## Формы и заявки

Бэкенда нет: формы формируют готовое письмо через `mailto:` и показывают подтверждение.
Состав заявки хранится в `localStorage` под ключом `stek-request-v1`, поэтому не теряется
при перезагрузке страницы. Для реальной отправки на сервер достаточно заменить обработчик
в `app.js` на POST-запрос к вашему API.
